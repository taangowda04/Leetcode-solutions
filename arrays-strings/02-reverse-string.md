## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used the two-pointer approach to reverse the character array in-place.
One pointer starts from the beginning and the other starts from the end.
The characters are swapped while the pointers move toward the center.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

Tested the solution locally using a normal string and a single-character
edge case before submitting it to LeetCode.
